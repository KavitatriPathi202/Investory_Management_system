# Integrated Inventory Management System (IMS)

## Overview
A modular Python application designed for small retail management using Python dictionaries, lists, and control structures.

## Features
- Full inventory CRUD management (Add, View, Update, Delete)
- Point-of-Sale (POS) billing with stock validation and receipt generation
- Low-stock alerts (Quantity < 3) and total asset valuation using dictionary iteration

## Technologies Used
- Python 3 (Lists, Dictionaries, Functions, Modules)

## Setup & Execution
1. Ensure Python 3.x is installed.
2. Open terminal/cmd in the project folder.
3. Run: `python main.py`

## Testing Instructions
1. Run `python main.py` and choose Option 1 to add a test product.
2. Choose Option 2 to process a sale and verify receipt generation.
3. Choose Option 3 to view asset valuation analytics.
